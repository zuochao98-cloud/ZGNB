02CRITERIA判定标准

基于战法匹配 / 买卖点纪律 / 仓位铁律
✓

正确交易 / CORRECT

  • 买点符合 B1/B2/B3/SB1 战法信号
  • J 值、BBI、量比位置确认时机
  • 卖出执行 S1/S2/S3 逃顶纪律
  • 仓位符合三层防火墙（≤40%）
  • 有明确止损/止盈规则并执行
✕

错误交易 / WRONG

  • 无战法信号追高买入（J 值 > 80）
  • 仓位超过铁律上限（>40%）
  • 未设止损被深套后被动割肉
  • 违反"少妇战法"频繁交易
  • 情绪化操作 / 听消息买卖
△

部分正确 / PARTIAL

  • 买点对但卖点过早（卖飞）
  • 买点对但仓位过轻错失主升
  • 未按战法分批止盈
  • 趋势未坏提前离场
  • 需结合后续行情二次判定
